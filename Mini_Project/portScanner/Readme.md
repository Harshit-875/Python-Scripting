# Multithreaded Python Port Scanner

## Description
A multithreaded TCP port scanner built in Python using sockets,
threading, and queues to efficiently scan open ports and grab banners.

## Features
- Multithreaded scanning
- Queue-based task management
- Banner grabbing
- Timeout handling

## Concepts Used
- TCP/IP networking
- Socket programming
- Threading & concurrency
- Service fingerprinting

## Usage
python port_scanner.py

## Legal Disclaimer
Scan only systems you own or have permission to test.
