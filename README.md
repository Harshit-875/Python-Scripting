# Python-Scripting

A collection of Python scripting projects focused on networking, automation, and cybersecurity fundamentals.

This repository will continue to grow with more Python scripts and cybersecurity-related projects in the future.

# 📌 Projects Included

## 1. basicTcpClient-Server

A simple TCP client-server communication project built using Python sockets.

### Features

* TCP socket communication
* Client-server interaction
* Networking basics
* Message exchange implementation

---

## 2. httpServer

A basic HTTP server implementation in Python.

### Features

* Handles HTTP requests
* Serves web pages
* Understands HTTP protocol basics
* Useful for learning web server concepts

---

## 3. portScanner

A Python-based port scanner used to scan open ports on a target system.

### Features

* TCP port scanning
* Service detection
* Beginner-friendly networking project
* Useful for cybersecurity learning
